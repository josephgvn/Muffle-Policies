Como silenciar o microfone no Mac com um atalho de teclado

O macOS tem uma tecla para ditado, mas nenhuma para silenciar o microfone. Cada app de chamada tem seu próprio atalho, e cada um só funciona se a janela estiver aberta em primeiro plano.

O Muffle adiciona um único atalho que silencia o microfone diretamente, em todos os apps ao mesmo tempo. O padrão é Control-Option-M, e você pode escolher a combinação que quiser.

Experimente o Muffle grátis por 3 diasEm breve na Mac App Store

Silencie com um atalho

  1. Instale o Muffle.
  2. Pressione Control-Option-M para silenciar. O ícone na barra de menus fica vermelho e uma pequena confirmação de “Silenciado” aparece.
  3. Pressione novamente para ativar.
  4. Para mudar, abra Ajustes do Muffle, clique no atalho e pressione uma nova combinação.
  • Segure o atalho enquanto estiver silenciado para falar e solte para silenciar de novo.
  • Clique com o botão direito no ícone do Muffle na barra de menus para silenciar na hora com o mouse.

Perguntas frequentes

O atalho funciona quando o app da chamada não está em primeiro plano?

Sim. Ele funciona a partir de qualquer app, até mesmo em apps em tela cheia.

Posso usar uma única tecla, como F5?

Sim. As teclas de função funcionam sozinhas; outras teclas exigem Control, Option ou Command.
