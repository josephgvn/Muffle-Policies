לחץ כדי לדבר ב-Mac, בכל אפליקציה

תכונת לחץ כדי לדבר שומרת אותך מושתק עד שתחזיק מקש לחוץ. זוהי הדרך הקלה ביותר לשמור על שקט בפגישות גדולות או בחדרים רועשים, אך רק אפליקציות מעטות כוללות אותה, וכל אחת משתמשת במקש שונה.

Muffle מוסיף אפשרות לחיצה כדי לדבר לכל אפליקציה ב-Mac שלך. בחר ״לחיצה כדי לדבר״ בהגדרות, החזק את קיצור הדרך כדי לדבר ושחרר כדי להשתיק שוב.

נסה את Muffle בחינם למשך 3 ימיםבקרוב ב-Mac App Store

שימוש בלחץ כדי לדבר

  1. 1

    התקן את Muffle.

  2. 2

    ב״הגדרות Muffle״, הגדר את ״מצב קיצור דרך״ ל״לחיצה כדי לדבר״.

  3. 3

    החזק את Control-Option-M לחוץ בזמן שאתה מדבר.

  4. 4

    שחרר. אתה מושתק שוב.

  • מעדיף מקש יחיד? הגדר מקש דיבור בהגדרות: ⌥ ימני, fn או לחצן עכבר נוסף.
  • בחר קיצור דרך נוח ב״הגדרות Muffle״, למשל מקש F.

שאלות נפוצות

האם לחץ כדי לדבר פועל ב-Google Meet?

כן. Muffle משתיק את המיקרופון עצמו, כך שלחץ כדי לדבר פועל ב-Meet, Zoom, Teams, Discord ובכל אפליקציה אחרת.

האם יש אפשרות ללחוץ כדי להשתיק?

כן. בחר ״לחיצה להשתקה״ והחזק את קיצור הדרך כדי להשתיק לרגע, כמו לחצן שיעול.

מדריכים נוספים

  • כיצד למנוע מאפליקציות לשנות את עוצמת המיקרופון ב-MacGoogle Meet, Chrome, Zoom ו-Teams משנים את רמת המיקרופון ב-Mac. נעל את עוצמת המיקרופון כך שאף אפליקציה לא תשנה אותה.
  • כיצד להשתיק את המיקרופון ב-Macארבע דרכים להשתקת המיקרופון ב-Mac: לחצן אפליקציית השיחה, הגדרות המערכת, קיצור דרך ו-AirPods, ומה עובד בכל אפליקציה.
  • תזכורת ״אתה מושתק״ לכל אפליקציית שיחותמדבר בזמן השתקה? Muffle מזהה ומציג תזכורת ״אתה מושתק״ ב-Google Meet, ב-Zoom, ב-Teams, ב-Slack ובכל אפליקציה אחרת ב-Mac שלך.
  • מדוע AirPods נשמעים פחות טוב במהלך שיחות ב-Macאוזניות AirPods עוברות למצב שיחה באיכות נמוכה כשהמיקרופון שלהן פעיל. הנה הסיבה, וכיצד לשמור על איכות שמע מלאה בשיחות Meet, Zoom ו-Teams.
