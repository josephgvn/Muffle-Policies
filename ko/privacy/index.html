최종 업데이트: 2026년 9월 30일

Muffle은 Mac의 마이크를 음소거하는 앱입니다. 사용자의 음성 데이터가 Mac 외부로 절대 유출되지 않도록 설계되었습니다.

Muffle의 마이크 활용 방식

Muffle은 통화 중에 마이크와의 무음 연결을 유지합니다. macOS는 마이크를 활발히 사용 중인 앱에만 AirPods 음소거 입력을 전달하기 때문에 이 무음 연결이 있어야 AirPods 누름 동작이 인식됩니다.

“음소거 중에 말하면 알림” 기능을 켜면, 음소거 중에 사용자가 말을 시작했는지 감지하기 위해 Mac 내장 마이크의 음량 레벨을 측정합니다.

Muffle은 오직 음량 수치만 감지합니다. 오디오를 녹음, 저장, 텍스트 변환하거나 외부로 전송하는 일은 절대로 없습니다.

수집하는 데이터

수집하는 데이터가 없습니다. Muffle에는 사용자 계정, 분석 도구, 광고 및 추적 기술이 전혀 포함되어 있지 않습니다. 자체 서버와 통신하지도 않습니다.

결제 정보

무료 체험과 일회성 구입은 Apple의 App Store를 통해 진행됩니다. 모든 결제 정보는 Apple이 안전하게 처리하며 개발사는 이를 열람할 수 없습니다. 해당 결제에는 Apple의 개인정보 처리방침이 적용됩니다.

Mac에 저장되는 설정 데이터

키보드 단축키 등의 사용자 설정은 Mac 내부의 Muffle 전용 저장 공간에만 보관됩니다. Muffle 앱을 삭제하면 설정 데이터도 함께 영구 삭제됩니다.

이 웹사이트

이 웹사이트는 얼마나 많은 사용자가 방문하고 어떤 페이지가 유용한지 파악하기 위해 Cloudflare Web Analytics를 사용하여 방문 횟수를 집계합니다. 쿠키를 사용하지 않고 기기에 아무것도 저장하지 않으며, 다른 사이트에 걸쳐 사용자를 추적하지도 않습니다. 이 집계에는 Cloudflare의 개인정보 처리방침이 적용됩니다.
