Le push-to-talk sur Mac, dans toutes vos applications

Le push-to-talk vous laisse en sourdine jusqu'à ce que vous mainteniez une touche. C'est le moyen le plus simple de garder le silence lors de grandes réunions ou dans des pièces bruyantes, pourtant peu d'apps le proposent, et chacune utilise une touche différente.

Muffle ajoute la fonction maintenir pour parler à toutes les apps sur votre Mac. Choisissez Maintenir pour parler dans les Réglages, maintenez le raccourci pour parler, et relâchez pour couper à nouveau le son.

Essayer Muffle gratuitement pendant 3 joursBientôt disponible sur le Mac App Store

Utiliser le push-to-talk

  1. 1

    Installez Muffle.

  2. 2

    Dans les Réglages de Muffle, réglez le « Mode de raccourci » sur « Maintenir pour parler ».

  3. 3

    Maintenez Contrôle-Option-M enfoncé pendant que vous parlez.

  4. 4

    Relâchez la touche. Vous êtes de nouveau en sourdine.

  • Vous préférez une seule touche ? Définissez une touche pour parler dans les Réglages : ⌥ droite, fn ou un bouton de souris supplémentaire.
  • Choisissez un raccourci pratique dans les Réglages de Muffle, par exemple une touche de fonction F.

Questions fréquentes

Le push-to-talk fonctionne-t-il dans Google Meet ?

Oui. Muffle coupe directement le micro, de sorte que le push-to-talk fonctionne dans Meet, Zoom, Teams, Discord et n'importe quelle autre app.

Existe-t-il une option pour couper temporairement le micro ?

Oui. Choisissez « Maintenir pour couper » et maintenez le raccourci pour couper un instant, comme un bouton de toux.
