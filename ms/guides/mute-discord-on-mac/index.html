Push to talk dan pintasan redam sejagat untuk Discord di Mac

Fungsi push to talk Discord memerlukan kebenaran tambahan pada Mac dan tidak berfungsi untuk Discord dalam pelayar web. Jika anda turut menyertai panggilan Meet atau Zoom, anda terpaksa menggunakan kekunci redam yang berbeza bagi setiap aplikasi.

Muffle memberikan satu kekunci untuk kesemuanya. Ketik untuk meredam, tahan untuk bercakap, atau tekan AirPods anda.

Cuba Muffle percuma selama 3 hariAkan datang ke Mac App Store

Sediakan push to talk untuk Discord

  1. 1

    Pasang Muffle dan benarkan akses mikrofon.

  2. 2

    Sertai saluran suara Discord.

  3. 3

    Ketik Control-Option-M untuk meredam atau nyahredam. Tahan semasa diredam untuk bercakap.

  4. 4

    Pilih kekunci anda sendiri dalam Tetapan Muffle, contohnya kekunci F.

  • Pintasan Muffle tidak memerlukan kebenaran Kebolehcapaian.
  • Kunci tahap mik anda supaya gandaan automatik Discord tidak mengubahnya secara berterusan.

Soalan lazim

Adakah ini sama seperti push to talk Discord?

Ia berfungsi dengan cara yang sama, tetapi untuk semua aplikasi serentak. Muffle meredam mikrofon itu sendiri, jadi Discord hanya mendengar kesenyapan sehingga anda menahan kekunci.

Bolehkah saya meredam Discord dengan AirPods?

Ya. Semasa panggilan suara, tekan tangkai AirPods untuk meredam atau nyahredam.
